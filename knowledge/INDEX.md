# 本仓库知识

> **不是合同。** 产品规则只在 [`site/core-docs/prd/INDEX.md`](../site/core-docs/prd/INDEX.md)；H5 / 知识问答需求只在 [`site/docs/INDEX.md`](../site/docs/INDEX.md)。  
> 本夹放可复用方法与讲解。冲突时改本夹，不改 `PRD.md` 去迁就回忆。  
> 不进切块、不进向量。文件名和标题都是 **`类型 · 主题`**。

## 类型

| 类型 | 用在 |
|---|---|
| 工作流程 | 可重复做的步骤 |
| 经验 | 已验证、可复用的做法 |
| 教训 | 踩过的坑 |
| 讲解 | 把概念讲清楚 |
| 案例 | 用真实问句对照 |
| 示意 | 接口打印等示意，不当合同 |

## 任务 → 打开

| 类型 | 标题 | 打开 |
|---|---|---|
| 工作流程 | 工作流程 · 文档工作台 | [`工作流程-文档工作台.md`](工作流程-文档工作台.md) |
| 讲解 | 讲解 · 检索链路与多意图 | [`讲解-检索链路.md`](讲解-检索链路.md) |
| 案例 | 案例 · 跨功能与单功能 | [`案例-跨功能与单功能.md`](案例-跨功能与单功能.md) |
| 示意 | 示意 · 接口打印 | [`示意-接口打印.md`](示意-接口打印.md) |
| 讲解 | 讲解 · K、n 与 Top-P | [`讲解-K与n与TopP.md`](讲解-K与n与TopP.md) |

一篇主类型可以在正文里再分「经验 / 教训」小节，文件名仍取主类型。

## 维护

- 新知识先定类型，再起文件名，登记本表。
- 不按日期堆文件，不按功能再建子夹。
- 流程变了才改对应篇；日常发版、修 bug 不改。
- 被整篇替换的原文进 `knowledge/history/`，不删。当前没有 history。
- 讲解稿与 [`site/docs/design/kb-qa/PRD-知识问答-v3.md`](../site/docs/design/kb-qa/PRD-知识问答-v3.md) 冲突时以 v3 为准。空状态建议问句等 UI 增量以 [`site/docs/design/kb-qa-feedback/`](../site/docs/design/kb-qa-feedback/INDEX.md) 为准。
