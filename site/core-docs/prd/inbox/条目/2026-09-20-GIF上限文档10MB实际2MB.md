# GIF 上限：文档 10MB，实际 2MB

- 记录日：2026-09-20
- 类型：文档偏差
- 状态：已升格
- 模块：VIP / 头像

## 现象

文档写 GIF 头像上限 10MB，超出 toast「GIF图片不能超过10M」。实际拦截已经是 2MB。

## 期望

改文档跟实现：现行改为 2MB。

## 证据

- 文档：升格前 [`prd/design/vip/brief/current.md`](../../design/vip/brief/current.md) 写 GIF 上限 10M，超出 toast「GIF图片不能超过10M」。权威正文仍以 [`prd/design/vip/PRD.md`](../../design/vip/PRD.md) 为准。
- 实际：线上拦截 2MB。Hayyo 业务代码不在本仓库（RQ-20），拦截发生在客户端还是服务端标 `needs-input`。

## 升格

2026-09-21 已写入 [`prd/design/vip/PRD.md`](../../design/vip/PRD.md) 上传 GIF 头像；现行说明 [`prd/design/vip/brief/current.md`](../../design/vip/brief/current.md) `{#logic-perk}`。口径：上限 2M，toast「GIF图片不能超过2M」。摘要见 [`prd/design/vip/changelog.md`](../../design/vip/changelog.md)。
