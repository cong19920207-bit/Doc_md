> **不当合同。** 现行产品规则仍以各功能 [`../design/`](../INDEX.md) 的 `PRD.md` 为准。本仓库工程事项去 [`../../../docs/inbox/INDEX.md`](../../../docs/inbox/INDEX.md)。  
> 人和 AI 日常只读本页看板。`条目/` 不进默认扫描。

## 怎么记

1. 复制 [`模板.md`](模板.md)。
2. 文件名：`记录日-压缩中文标题.md`，放到 `条目/`（不要英文缩写）。
3. 在本表**最上**加一行，**记录日**必须能看见。
4. 确认要做再写入对应功能 `PRD.md`（或另开确认）；本表状态改成「已升格」，留指针。

类型：需求 / 想法 / 优化 / bug / 文档偏差。  
状态：开放 / 以后再说 / 已升格 / 已完成 / 不做。
