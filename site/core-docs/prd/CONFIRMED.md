## 已确认（RQ-01～RQ-21）

| ID | 现行口径 |
|---|---|
| RQ-01 | 用户钱包只有 **金币**（付费）和 **宝石**（免费）。金币分可交易 / 不可交易：仅币商从平台买入可交易金币，卖给用户后用户侧即为不可交易。充值币不是独立钱包（金币来源标签）。**钻石、游戏币删除。** 积分只用于提现，不是用户第三套钱包。 |
| RQ-02 | **贵族下线。** 付费身份只有 VIP。贵族订阅入口、贵族表情、注销「在订贵族」拦截、榜单贵族勋章：无效，展示改 VIP。 |
| RQ-03 | **用户等级现行。** 经验 = 房间停留 + 金币消费/4000（取整）。后台「没等级」作废。无贵族经验加成，无钻石经验。 |
| RQ-04 | 对外品牌 **Hayyo**。默认昵称 / 房间名 / 后台重置前缀 = `player`。`Samer_{ID}`、`Samer+{XID}`、「进入 Samer」不当现行。scheme `samer` / `parchisw` 本轮不改名。 |
| RQ-05 | 登录注册、绑/换绑、改密、注销、提现短信共用配额：同设备 + 同号，GMT+3 自然日 ≤10。币商自充短信单独（设备 10、号 50），不与登录配额合并。infra 里按场景 2～3 条、9 个 TBD 不当现行。 |
| RQ-06 | 新用户必须在资料确认选 **男或女** 才能进首页，选后不可改。Not Specified 不是线上默认。 |
| RQ-07 | **无主播、无工会/公会、无家族**，相关能力全站删除。注销仍拦截：封禁/冻币、未绑定、30 天冷却。「查看取消订阅步骤」只说明商店订阅，不是 VIP 门闩。 |
| RQ-08 | 互关即好友；无好友验证、无申请箱。陌生人 IM：72 小时内对同一人最多 3 条（文字 / 表情 / 房间分享，不含礼物）。profile 验证开关、消息「每天 20 条」不当现行。「30 天内最多触发 1 次」仍待定。 |
| RQ-09 | 官方房满员/邀请 = **15** 个已占麦；非官方 = **8**。无房主专属麦、老板位、自动上麦。 |
| RQ-10 | AR / EN / TR 房间列表强制置顶目前唯一的阿语官方房，不受热度影响。主播房坑位已随 RQ-07 删除。 |
| RQ-11 | 水果机档位 **10 / 500 / 2K / 50K**，默认 **10**。原文 10/100/1000/10000 及默认 1 金币不当现行。Bounty Racing / Lord of Olympus 档位仍待定（摘录数字不是已确认档位）。 |
| RQ-12 | 休闲仅 Ludo / Carrom / Block Crush，写在 `casual-game`。水果机 / 动物机 / Bounty / Olympus 只在 `room-game`。`casual-game` 里「Casual Games = 数值游戏」不当现行。幸运数字 / 掷色子仍是房间工具。 |
| RQ-13 | C 端拉新跟 V1.4.0：不展示审核中 / 待领取；「已领取」改 **已发放**；落地为带分享者信息的 H5；拉人宝箱可不按序领；新手玩法新注册即可见。开通/结算/领取校验不重写。团队 Banner 本版不做。 |
| RQ-14 | 积分只兑 USD。展示最多 **16** 位，超出加 `+`；与原文「第 9 位」冲突时以 16 位为准。HABBY、TLXX 前缀保留。 |
| RQ-15 | 币商 WhatsApp / 群发 / 自动回复 / Agency 分类作废。无自动冻币；手动冻结 + 退款欠款限制转账（只动代理账户）。自充与官方打款都是现行买可交易金币的路径。自动补币仍待定。 |
| RQ-16 | 「还差 XXX 金币」**非现行**。主线停在 V1.4.0；等 V1.5.0 升格后再收。原文已写 V1.4 及之前不返回该值。 |
| RQ-17 | 靓号 **仅后台发放**（含 VIP 联系运营挑选后下发），商城不卖。「购买靓号」句作废。**本版无头饰卡道具**（商城/背包/房间/后台/礼包全部去掉）。头饰卡 ≠ 头像框。 |
| RQ-18 | 新人礼包可配发当前仍存在的虚拟商品、道具、金币、宝石等；**不发头饰卡、钻石**。具体发哪几件由服务端配置，不写死默认 SKU。开关、同设备最多三次、只弹一次、V1.1.0 推荐房间卡片仍按原文。 |
| RQ-19 | 后台钻石统计 / 兑换 / 账本字段作废。运营房与官方房考核仍做；「主播房」过滤作废。Ludo/Donimo 局数当旧字段名残留，本轮不改映射。拉新后台可保留审核中等内部态；**C 端与后台终态都是「已发放」**，不再用「已领取」。C 端不展示审核中 / 待领取。 |
| RQ-21 | **没有游戏房模式。** Party 可见房间都是语聊房。运营侧分类仍有官方房 / 运营房 / 币商房；密码房是房间属性，不是一种房间模式。**房间内游戏仍在**：`room-game`、房间内休闲面板、幸运数字 / 掷色子。列表/跟随里的 ludo 房、domino 房、桌球房、语聊↔游戏切换、游戏房专属背景/榜单入口：无效。休闲「房间外匹配」原文写明不进 Party 列表，不把它定义成游戏房模式，也不在本条删除。 |

RQ-20：Hayyo 业务代码不在本仓库，对照代码延期。
