## 范围
- App 房间：大厅、进房、麦位、资料、礼物、密码房、音乐、发图、侧边栏活动、计分牌、周星、爆奖礼物客户端、房间内游戏入口。
- Party 可见房间都是语聊房。运营侧分类仍有官方房 / 运营房 / 币商房；密码房是房间属性，不是房间模式。
- 房间内游戏仍在：[`../room-game/PRD.md`](../room-game/PRD.md)、房间内休闲面板、幸运数字 / 掷色子。
- 无游戏房模式，无语聊↔游戏切换，无游戏房专属背景/榜单入口。无主播、无工会/公会、无家族。无房主专属麦、老板位、自动上麦。礼物面板无头饰卡 tab。
- 官方房满员/邀请 = **15** 个已占麦；非官方 = **8**。
- 房间列表置顶见 [`../room-list/PRD.md`](../room-list/PRD.md)，本文不复制置顶全文。
- 爆奖礼物后台见 [`../admin/PRD.md#admin-gift-burst`](../admin/PRD.md#admin-gift-burst)；本文只写客户端。

### 安卓消息页通知权限

背景：安卓端因历史包袱，手机权限默认不会开启通知权限，导致用户进入应用默认无法收到推送消息。

优化安卓逻辑：进入 Message 页面检测当前应用是否开启权限通知，如果没有开启弹窗提示开启权限，点击按钮跳转系统设置开启权限，若关闭弹窗或关闭权限，7天（自然日）内不再弹起弹窗，直到下一个周期进入 Message 页面。

### 幸运数字与掷色子

幸运数字 / 掷色子仍是房间工具。房间幸运数字、掷色子保留服务防刷屏逻辑：X秒内最多能输入Y次（X=30，Y=30），两个游戏限制分开计算，跨房间不重新计算；超过次数提示：“操作频繁，稍后再试”。

### 礼物面板

旧包使用不受影响。双端同一套。私聊无对象区、IM 入口 New、引导 2 步在 [`../messaging/PRD.md`](../messaging/PRD.md) 只放指针。VIP 体验券时间格式指向 [`../coupon/PRD.md`](../coupon/PRD.md)。

#### 面板介绍与数量

接收对象区在顶端，默认全麦；左侧用户明细，右侧全麦/全房。选全房间/全麦气泡 2 秒。分类顺序：经典、VIP、爆奖、背包、道具。无头饰卡 tab。向上/下滑动超过说明高度后说明离场，松手再入场覆盖礼物上方。关面板再开保留礼物与数量选择；离房后销毁重置。New 标记按后台。角标最多 3 个，超过只显示前 3；同一礼物排序：活动、周星、爆奖、全站。二次点击选中礼物打开说明。列表改为上下滑，右侧进度条，倍率随手指。财产默认左上；有首充标记则在金币后，点开首充；无则箭头进充值。选中宝石礼物切宝石余额。数量选择只改 UI。道具背包弹窗仍盖在礼物面板上，高出部分隐藏，关闭后恢复。

#### 接收对象
