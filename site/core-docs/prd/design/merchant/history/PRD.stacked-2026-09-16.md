## 现行确认口径

> 2026-09-15 写入。全文见 [`../../CONFIRMED.md`](../../CONFIRMED.md)。**本块优先于下文与之冲突的旧句。** `history/` 不改。V1.5.0 非权威。

- 全局不作现行：钻石、游戏币、头饰卡、贵族、主播、工会/公会、家族、游戏房模式。
- 头饰卡 ≠ 头像框。无游戏房模式，房间内游戏仍在。钱包只有金币（付费）+ 宝石（免费）；积分只用于提现。

**本模块：**
- 代理账户 = 可交易金币；转到用户后不可再交易。
- WhatsApp / 群发 / 自动回复 / Agency 已标删除，不当现行。
- 无自动冻币；手动冻结 + 退款欠款拦转账（只动代理账户）。自充与官方打款都现行。自动补币待定。
- 自充短信单独（设备 10、号 50），不与登录配额合并。
