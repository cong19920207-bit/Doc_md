3.14.1 VIP - 数值及计算逻辑

| 需求描述 |  |
|---|---|
| 优先级 |  |
| 输入/前置条件 |  |
| 需求描述 | 功能描述：<br>VIP是基于付费贡献的保级制用户身份体系。不同的VIP等级，提供提供不同的展示和功能特权，使付费用户拥有区别于普通用户的荣誉展示和使用体验。<br>VIP是保级制，用户达到VIP的某个等级后，身份会维持一个月；用户保级所需的金额，要低于直接升上去的金额，以此维持用户的持续充值。<br>单位<br>- VIP以财富值为计量单位<br>- 财富值来源：<br>通过充值得来的金币（商店充值、币商，以及后续接入的第三方充值方式）计算财富值，200金币=1财富值（1月19日更新数值）；<br>运营后台加币时，若操作类型为“工资抵扣”（删除）和“对掉单的用户补单”，则计算财富值，200金币=1财富值（1月19日更新数值）；<br>- 除以上途径外，其他获取金币的方式均不加财富值，包括：非上述两种操作类型的运营后台加币、系统返币等；订阅贵族的花费及贵族返币，不加财富值<br>- 后台扣币，不减财富值；<br>各等级财富及权益<br>- VIP财富值达到最高等级的保级线时，保持在保级线的数值，不再继续提升<br>升级、保级、降级策略<br>- VIP每轮周期为30天，自用户首次充值（财富值有数字）开始，开启30天周期；为方便任务处理，VIP结算时间统一为每天GMT+3时区的12点，因此实际周期时间比30天略长<br>- VIP周期在升级、降级、保级成功的各个节点重置，因此每个用户的周期不一致<br>升级：在本周期内，达到下一等级所需财富值<br>- 财富值数字保持，升级到下一等级，发放下一等级的特权并回收当前等级的聊天气泡、头像框、座驾<br>- 结束当前周期，并开启新的一轮30天周期<br>保级：在本周期结束时，若用户没有达到下一等级所需财富值，但达到了本等级保级财富值<br>- 将财富值重置为本等级的初始财富值，保持本等级特权<br>- 开启新的一轮30天周期<br>降级：在本周期结束时，若用户没有达到本等级保级财富值<br>- 将财富值重置为上一等级的初始财富值，发放上一等级的特权并回收当前等级的聊天气泡、头像框、座驾<br>- 开启新的一轮30天周期<br>退款处理<br>用户发生退款后，VIP财富值以200退款金币=3财富（1月26日修正）值的比例进行扣除<br>退款后，因财富值下降而导致的VIP等级下降：<br>- 保持退款后的财富值，不进行充值财富值至上一周期初始值的操作；发放上一等级的特权并回收当前等级的聊天气泡、头像框、座驾<br>- 开启新的一轮30天周期<br>上线时初始定级<br>- 目前运营有手动结算的旧VIP体系，并有一部分用户使用；在新的VIP体系上线后，针对原VIP体系的用户，产运会提供一份“UID+财富值”的对照表格，服务端将这些用户的财富值订正，直接赋予这些原VIP体系用户相应的等级和权益。（1月26日删除） |
| 补充说明 | 因每天12点的结算处理需要一定时间，因此每次发放商店商品及密码房权限时，多发放1h时间，以避免结算还未完成而原有的VIP特权失效的情况<br>在正式发包之后，线上再开始跑VIP相关的任务、计算VIP体系的等级&周期数据。在服务端代码上线，到正式发包之间的时间，仅针对特定的内部UID加财富值（用以测试），线上其他用户不受影响。 |
