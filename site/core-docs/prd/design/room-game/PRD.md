### 功能概述

房间内新增小游戏“水果派对”，采用H5制作，以便于游戏的调整迭代。本游戏在语聊房侧边栏/半屏打开。

#### 风控预警

两款分开配置。5 分钟实时检测，钉钉群+邮件：低水位（水线 ≤ X）；7 天内累计中奖 ≥ Y；单人 7 天累计中奖 ≥ Z（X/Y/Z 可配）。限频：1 小时最多 50 次（两款分开，数值相同）。

#### 全局游戏重连弹窗

大厅/房间游戏重连提示为即时队列，排序 3（协议之后、其他业务弹窗之前）。队列规则权威在 [`../infra/PRD.md`](../infra/PRD.md)；本条只定义该弹窗归属本功能。

#### 与休闲游戏共存

用户在房间玩数值游戏时房间开启休闲：休闲保持最小化；关掉数值弹窗后，数值仍保持最小化。休闲侧细则见 [`../casual-game/PRD.md`](../casual-game/PRD.md)。
