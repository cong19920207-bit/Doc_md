## 怎么记

1. 复制 [`模板.md`](模板.md)。
2. 文件名：`记录日-压缩中文标题.md`，放到 `条目/`（不要英文缩写）。

4. 确认要做再升格到 `design/<专题>/` 出 PRD；本表状态改成「已升格」，留指针。

类型：需求 / 想法 / 优化 / bug / 文档偏差。
