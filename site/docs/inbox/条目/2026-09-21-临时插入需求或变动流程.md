# 临时插入需求或变动：文档怎么进

- 记录日：2026-09-21
- 类型：需求
- 状态：开放
- 模块：文档工作台 / 知识问答

## 现象

上一条是「已有知识点怎么改」。本条是另一条：忽然要插一条新需求，或插一处尚未写进现行 `PRD.md` 的变动，没有可跟着做的临时入库流程。

现在要么进 `workspace/`（不进问答），要么直接改现行 `PRD.md`（等于已收录）。缺中间态：先能查、能问、能标「临时」，以后再升格或作废。

## 期望

有一份可执行的「临时插入」流程（文档或管理站向导均可，未定）：新需求或变动先落到哪份文件、怎么标明临时、要不要切块/重建、问答如何区分现行与临时、确认后如何升格进 `PRD.md` / brief，或到期作废。

不覆盖整版 Word 洗稿，也不替代「改已有知识点」。

未定：只写进 `knowledge/` 工作流程，还是管理站做成向导；临时稿是否进向量。

## 证据

- 文档：版本三态见 [`knowledge/工作流程-文档工作台.md`](../../../../knowledge/工作流程-文档工作台.md) 与 [`prd/VERSIONS.md`](../../../../prd/VERSIONS.md)：工作区不当现行；补丁规则要进功能 `PRD.md` 才算收录。立项前可记 [`inbox`](../INDEX.md)，但 inbox 不进切块。
- 实际：没有「先临时插入、可被问答或索引看到、再决定升格」的操作清单。
