本文是**独立增量 PRD**，目录在 `site/docs/design/h5-theme/`。只覆盖：本仓库 H5 工作台的配色主题清单、顶栏切换、本地记住选择。不修订、不替代 `design/h5-kb/`、`design/kb-qa/`、`design/kb-qa-feedback/` 正文。

**需求状态：** 已确认（2026-09-19 对话：只做本工作台；几套配色都保留；控件用原生下拉框；开工前先写本文）。  
**实现状态：** 未实施正式切换。现网仅有 `?theme=` 预览与对照页。

**本次修订（2026-09-19，USER_DECISION「按建议」）：**

1. 从未选过 / 无痕 / 清空存储 / 非法存储值 → 生效 **边缘行者粉**（`d-edgerunners`）。不自动把空存储写成键值；已写入 `default`（现网蓝灰）的本机不迁移。  
2. 把边缘行者 token 写入 `style.css` 的 `:root`（与现有 `themes/d-edgerunners.css` 一致），避免首次打开先闪蓝灰。现网蓝灰抽成额外皮肤文件 `themes/default.css`（实施时新增）。  
3. 审查残留风险不另开优化轮：R1/R4/R5 随 STEP 做；R3 不改对照页标题；R2/R6 由本条 `:root` 对调消化。

## 0. 名词（先读这段）

| 说法 | 指什么 | 不是什么 |
|---|---|---|
| **工作台** | 浏览器打开 http://127.0.0.1:18765/feature-interaction/ 看到的那一页。顶栏有四个 Tab：客户端 ↔ 后台、客户端交叉、文档索引、知识问答 | 不是 `/docs/` 文件目录，不是运营后台 layui 皮，不是 Hayyo App |

一句话：人还在现在这个 H5 里干活，只在顶栏用选择框换配色。

## 1. 摘要

把已经做好的五套未来配色，加上现网蓝灰，做成工作台内可切换的 6 套主题。选择写在本机浏览器里，刷新后仍生效。四个 Tab 和弹层跟同一套色。不改问答检索、不改图谱数据、不改页面结构。

## 2. 背景、问题与目标

### 2.1 现状

- 工作台强制深色，主色蓝 `#6ea8fe`，写在 `site/feature-interaction/style.css` 的 `:root`。
- 已有对照皮肤：`themes/a-gits.css`、`b-2049.css`、`c-nightcity.css`、`d-edgerunners.css`、`c-prime.css`，以及 `themes/_apply.css`。
- 仅当 URL 带 `?theme=` 时，`theme-preview.js` 才加载皮肤；底部有「正在预览」条。对照入口：`/feature-interaction/themes/`。
- 无顶栏切换，无记住选择。图谱域色已改为读取 CSS 变量（`app.js` `domainColor`），换皮后仍需重绘节点。

### 2.2 核心问题

1. 几套配色都被认为可用，不能只留一套、丢掉其余。  
2. 对照页适合挑选，不适合每天用：人要离开当前 Tab 去换链接。  
3. 刷新后预览主题会丢。

### 2.3 目标与成功标准

| 目标 | 成功标准 |
|---|---|
| G1 主题可切换 | 顶栏下拉框能选 6 套之一，选完四个 Tab 配色立刻跟上 |
| G2 选择可记住 | 刷新、关标签再开同一浏览器，仍是上次那套 |
| G3 默认不惊吓 | 从未选过的人看到的是边缘行者粉（不是现网蓝灰） |
| G4 功能不被换皮打坏 | 问答、关系图、文档索引、配置/明细/热度弹层行为与换皮前一致 |

## 5. 功能规则

### 5.1 主题清单

`<select>` 选项顺序固定如下。`id` 是存储值和 CSS 文件名。

| 顺序 | id | 显示名 | 文件 |
|---|---|---|---|
| 1 | `default` | 现网蓝灰 | `themes/default.css`（实施时把现行 `:root` 蓝灰 token 抽出；须含 `--edge: #4a5160`） |
| 2 | `a-gits` | 攻壳青 | `themes/a-gits.css` |
| 3 | `b-2049` | 2049 琥珀 | `themes/b-2049.css` |
| 4 | `c-nightcity` | 夜之城黄 | `themes/c-nightcity.css` |
| 5 | `d-edgerunners` | 边缘行者粉 | 无额外文件（写入 `style.css` `:root`，token 与现有 `themes/d-edgerunners.css` 一致） |
| 6 | `c-prime` | 黄主色 | `themes/c-prime.css` |

**首次生效（未选过）：** 存储空或非法 → 生效 `d-edgerunners`，不加载额外皮肤。下拉当前项显示「边缘行者粉」，即使它不是列表第一项。

**加载规则：** `d-edgerunners`（含空/非法视同该项）不挂额外皮肤 link。其余 5 个 id 同时加载对应 css + `themes/_apply.css`（把硬编码色接到变量上）。`themes/d-edgerunners.css` 可留作对照页图鉴，工作台默认路径不必再加载它。

### 5.2 下拉框

- 控件：原生 `<select>`（用户确认「2」：不要自定义带色点菜单）。  
- 位置：工作台顶栏右侧，四个 Tab **之外**；四个 Tab 都显示，不藏在「知识问答」动作区里。  
- 标签：旁边写「主题」，`select` 有 `aria-label="主题"`。  
- 当前项与已生效主题一致。  
- 换选项后立刻换皮，不必刷新、不必跳转。

### 5.3 记住选择

- 键名：`hayyo-h5-theme`。  
- 合法值：§5.1 的 6 个 id。非法值或空 = 生效 `d-edgerunners`，不当作 `default`（蓝灰）；空键不自动写入。  
- 只存本机。已保存 `default` 的本机仍是现网蓝灰，不清、不改写成粉。  
- 清站点数据或无痕窗口 → 边缘行者粉。

### 5.4 URL

- 日常使用不依赖 `?theme=`。  
- 若仍带 `?theme=` 且 id 合法：本次打开用该 id，并写入 `localStorage`（方便从对照页跳进来）。`view=` 预览用参数可保留，正式切换不依赖它。

### 5.5 换皮时要跟上的表面

必须变色：顶栏、Tab 选中态、主按钮「发送」、会话选中、图谱节点域色与连线、文档索引阅读区链接/选中、问答弹层与出处侧栏。

必须不变：Tab 数量与名字、三栏/对话布局、检索与问答接口、节点数据、赞踩刷新行为。

## 6. 实施计划（开工顺序）

业务代码状态：`NOT_STARTED`。按下列三步做，做完用 §7 验收。不要顺手改问答或图谱逻辑。

### 步骤 A · 主题运行时

1. 把 `theme-preview.js` 收成主题运行时（可改名 `theme.js`）：读 `localStorage` / `?theme=` → 挂或卸皮肤 CSS。  
2. 脚本仍放在 `index.html` 的 `<head>`，尽量在首屏绘制前套色。  
3. 暴露 `applyTheme(id)`：换 `<select>` 时调用；非法 id 回退生效 `d-edgerunners`（不写非法值）。  
4. 把 `style.css` `:root` 换成边缘行者 token；把现行蓝灰 `:root` 抽到 `themes/default.css`。不重写 `style.css` 布局结构。  
5. 换主题后若存在 `GraphApp`，重绘筛选与关系图（调用现有渲染，不改布局算法）。

### 步骤 B · 顶栏下拉框

1. 在 `index.html` 顶栏加「主题」+ `<select>`，选项即 §5.1。  
2. 样式只做高度/边框对齐现网顶栏控件，不新做菜单组件。  
3. `qa-top-actions` 继续只在问答 Tab 显示；主题下拉框四个 Tab 都在。  
4. 去掉底部 `.theme-preview-bar`。

### 步骤 C · 收口

1. 对照页可留：链接改为打开工作台（可带 `?theme=`）。  
2. 不改 `qa.js` 业务、不改 kb-api。  
3. 用 §7 清单在浏览器走一遍。

### 明确不在本期步骤里

- 重写 `style.css` 布局结构、引入 React/Vue、把 6 套色内联进一份巨大 CSS。允许且必须：只替换 `:root` token，并把旧蓝灰抽成 `themes/default.css`。  
- 为 `/docs/` 或 admin-skin 接同一套切换器。

## 8. 回滚

去掉顶栏 `<select>`、停用主题运行时、清 `hayyo-h5-theme` 之后，页面会停在 **边缘行者粉基线**（`:root` 已对调），不是旧蓝灰。若要回到改主题切换之前的蓝灰，还须还原 `style.css` `:root` 并去掉 `themes/default.css`。`themes/*.css` 其余文件可留。不涉及数据库与 API。
