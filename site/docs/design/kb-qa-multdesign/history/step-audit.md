## 2. 逐项问题

严重度：`error` 不修不能出验证版；`warn` 修验证版时应一并处理。

### [验收不可测] 记录级断言没有比较键

- **严重度**：`error`
- **位置**：Q03、Q08、Q21、A15 等验收行；总览里用「N 个版本 / 前 40 个仍在 / 执行=3 / +1」收束的行
- **证据**：技能要求验收若针对「这些记录」，必须比较同一输入快照下的稳定 ID 或字段元组，不能只比数量。PRD 这些条款比的是对象，不是个数：
  - AT-12 / T10：原来的那些会话仍在，不是「还剩 40 个」
  - AT-09：同一条 User、同一个逻辑回合，新增的是回答版本
  - AT-31：赞踩留在各自的回答版本上
  - T49：被接受的 1 次发送 + 2 次刷新计入，那一次重传的请求不计入
  - T51：同一次执行里某个 `feature_id` 只 +1
- **本次未改**。验证版应写成：比较 `conversation_id` 集合、`message_id` / 逻辑回合 id / 回答版本 id、执行 id 集合，以及 `feature_id` 多重集。PRD 没要求顺序的，不额外加顺序断言。

### [依赖问题] AT-03 只挂在 Q17，恢复路径在 Q16

- **本次未改**。应把 AT-03 的「恢复且不重置预算」子条款改挂 Q16，或把 Q16 写成 Q17 验证该子条款的前置。
