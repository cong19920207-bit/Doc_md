# M1 临时契约草案

> 里程碑：M1 能登录、接口不再裸奔  
> 状态：阶段快照（已被 [`../../contracts/kb-auth/contract.md`](../../contracts/kb-auth/contract.md) 覆盖）  
> 日期：2026-09-19  

本文件只冻结 M1 落地名与分档，不改 PRD/STEP 正文。

## 表

| 表 | 用途 |
|---|---|
| `qa_rounds` | 保留，不删 |
| `kb_roles` | 角色；预置 `role-super` / `role-user` |
| `kb_role_permissions` | 勾选；存产品文案：知识问答、进管理模块、配置、重建、问答明细、功能热度、对话审计、健康、操作审计、反馈汇总 |
| `kb_accounts` | 账号；`tenant_id` 可空；一账号一 `role_id` |
| `kb_sessions` | 服务端 Session；绝对 7 天；`revoked_at` 作废 |
| `kb_login_locks` | 按用户名失败计数 / `locked_until` |
| `kb_audit_logs` | 登录成败与改密打点；无密码明文 |

已有 MySQL 卷：进程启动 `AuthStore.ensure_schema()`（`CREATE IF NOT EXISTS`），不重跑 `init.sql`。

## 引导与密码

- 环境变量：`KB_BOOTSTRAP_USER`（默认 `admin`）、`KB_BOOTSTRAP_PASSWORD`（compose 默认 `changeme`）
- 仅 `kb_accounts` 为空时创建一次；重启不重置哈希
- KDF：`pbkdf2_sha256`（`cryptography` PBKDF2-HMAC-SHA256）；库内前缀 `pbkdf2_sha256$<iterations>$...`
- 无自助注册路由

## Cookie 与 Session

- 名：`hayyo_kb_sid`
- `HttpOnly`；`SameSite=Lax`；`Path=/`；`Max-Age=604800`
- `Secure` 仅 HTTPS
- 不用 JWT；响应体无 token
- 登出 / 改密：作废该 Cookie 对应或该账号全部 Session

## API（均在现网 nginx `location /api/kb/` 下）

| 方法路径 | 鉴权 | M1 行为 |
|---|---|---|
| `POST /api/kb/auth/login` | 白名单 | 成功 `Set-Cookie` + `{ok,id,username}`；失败 401 |
| `POST /api/kb/auth/logout` | 白名单 | 作废 Session、清 Cookie |
| `GET /api/kb/auth/me` | 白名单（无 Session 则 401） | `id` 即 `ME_ID` |
| `POST /api/kb/auth/password` | 须登录 | 旧密+新密；成功后全部 Session 死 |
| `GET /api/kb/health` | 匿名 | 保留健康灯；本里程碑不强制登录 |
| `GET\|PUT /api/kb/config` | 登录 +「配置」 | 未登录 401；无勾选 403 |
| `POST /api/kb/reindex` | 登录 +「重建」 | 同上 |
| `GET /api/kb/rounds`、`GET /api/kb/rounds/{id}` | 登录 +「问答明细」 | 同上；不叠加大门 |
| `POST /api/kb/ask` | 未登录 401 | 角色 403 留 STEP-005 |
| `GET /api/kb/heatmap` | 未登录 401 | 角色 403 留 STEP-012 |
| `POST /api/kb/rounds/{id}/feedback` | 暂仍匿名 | 提问人校验留 STEP-006 |

锁定：同一用户名连续 5 次失败锁 15 分钟；第 6 次即使密码正确 401。失败文案「用户名或密码不正确」；锁定文案含「稍后重试」。

预置普通用户勾选恰好 {知识问答}。超管 `is_super` 视为全勾选。
