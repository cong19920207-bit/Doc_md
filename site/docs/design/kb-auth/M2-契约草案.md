## API

| 路径 | 行为 |
|---|---|
| `POST /api/kb/ask` | 未登录 401；已登录无「知识问答」403；`user_id` 只取 Session |
| `POST /api/kb/rounds/{id}/feedback` | 须登录；仅提问人 2xx，他人/管理员 403 |
| `GET/POST /api/kb/conversations` | 须登录；列表/创建，按 `ME_ID` 隔离，上限 40 |
| `GET/PUT/DELETE /api/kb/conversations/{id}` | 只能操作自己的会话；删除不删 `qa_rounds` |

表：`kb_conversations`。登录后 H5 列表权威为云端，不导入 `hayyo-kb-qa-conversations-v1`。
