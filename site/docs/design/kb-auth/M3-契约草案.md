## H5

- 问答顶栏无配置/重建/明细/热度四钮，保留 `#qaHealth`
- 账号菜单：退出、修改密码；有「进管理模块」才出现 `ADMIN_ENTRY`（`/kb-admin/`）
- 四 Tab `MAIN_TABS_SEQ` 不变
- 登录且有知识问答：空状态 `CHIP_FIXED` 四对 + `CHIP_HEAT`（最多 4）；未登录不请求热度

## 管理站

- URL：`/kb-admin/`（nginx `auth_request` → `GET /api/kb/auth/admin-gate`）
- 无「进管理模块」：无入口；管理 URL / gate 403
- 自做页面，不引用 admin-skin
- 页级接口只按勾选，不叠加大门（R-API-DOOR）
- `ROLE_MINGXI`={进管理模块, 问答明细}：能看明细，配置/重建入口无且写接口 403

## 超管

| 路径 | 行为 |
|---|---|
| `POST /api/kb/admin/accounts` | 开户，指定初始密码与角色；不强制首次改密 |
| `PATCH /api/kb/admin/accounts/{id}` | 启用/禁用/改角色；禁用立即作废 Session；不能去掉最后一名启用超管 |
| `GET/POST /api/kb/admin/roles` | 角色勾选只用 `PERM_CHECKBOX` |
| `POST /api/kb/admin/unlock` | 清失败次数后立即能登录；非超管 403 |

对话审计：`GET /api/kb/admin/conversations` 需「对话审计」，可见全站云端会话 id。
