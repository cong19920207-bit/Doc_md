## 审计与汇总

| 路径 | 行为 |
|---|---|
| `GET /api/kb/admin/audits` | 需「操作审计」；存储 `kb_audit_logs`，≠ `qa_rounds` |
| `PUT /api/kb/config` | 打点 `config_update`；可见字段名 = 本次 writable 键；无 Key/私钥/密码 |
| `POST /api/kb/reindex` | 打点 `reindex`，主体为操作者 `ME_ID` |
| `GET /api/kb/admin/feedback-summary` | 需「反馈汇总」；被踩列表 `SUMMARY_DOWN`；点进详情 `round_id` 相等；无新采集口 |

## 证书

| 路径 | 行为 |
|---|---|
| `POST /api/kb/admin/tls` | 仅超管上传 PEM，只保存，不启用 |
| `POST /api/kb/admin/tls/enable` | 校验通过才写 `https.enabled`；坏证书协议不变 |
| `POST /api/kb/admin/tls/disable` | 关闭回 HTTP |
| `GET /api/kb/admin/tls` | 状态；无私钥回显；本机非 80/443 时 `redirect_https=false` |

nginx：Host 带非标准端口（如 `:18765`）即使已启用也不强制跳 HTTPS。无 ACME，后台改不了端口。

## compose

- `HAYYO_WEB_PORT` 默认 18765 → 容器 80
- `HAYYO_TLS_PORT` 默认 18769 → 容器 443（宿主机 443 默认连不上）
- 正文无 `0.0.0.0`；本机默认 18765 HTTP 仍可登录问答
