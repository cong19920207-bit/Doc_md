# 案例 · 多轮对话窗异常

> **给 AI 用。** 真实对话窗逐轮对照：用户原句、当时窗口里已有什么、用户可能要什么、改写实际产出什么、气泡里出现什么。  
> **不是合同。** 产品规则以 [`site/docs/design/kb-qa/PRD-知识问答-v3.md`](../../site/docs/design/kb-qa/PRD-知识问答-v3.md) 为准。  
> 证据：本机 `hayyo_kb.qa_rounds`。`created_at` 为库内 UTC；本地 UTC+8 约 +8 小时。

## 阅读规则

- 下面每个「轮」是一次 `POST /api/kb/ask`，对应一行 `qa_rounds`。
- 「用户可能要」是从原句和窗口位置推断的意图，**不是**已确认需求。
- 改写三件套以日志为准：`rewrite_query` / `same_topic` / `named_feature_ids`。
- 同一 `conv_id` = 用户没点「新对话」。不要把各轮拆成四个新会话来理解。

## 0. 一句话

产品只做「Hayyo 功能知识题 → 改写独立问句 → RAG → 按 brief 块回答」。  
用户在**同一对话窗**里接着确认、改口吻、应酬、问无关的人，系统仍把每句当新知识题：有的整题重答，有的 `gen_fail`。

## 1. 当时每轮实际带上的上下文

界面气泡可以一直堆。送给改写 / 检索 / 生成的只有这些：

| 字段 | 实际含义 |
|---|---|
| `history` | 最近最多 **5 条用户原句**。不含助手回答正文 |
| `last_chunks` | **上一轮成功**进生成的 Top 块公开身份（有 `excerpt`，当时无 `content`） |
| `same_topic` | 改写给的布尔：true 并入上轮块；false 整份丢掉 |
| `named_feature_ids` | ≥2 则每功能一路；0 或 1 则两库单路混搜 |

没有：问句类型、域外短路、多线程上下文、多轮块累积。  
拒答口径只有「重排 0 块」或「块里没写」，没有「这不是规则问题」。

```text
用户看见：本窗全部气泡（问 + 答）
模型看见：≤5 句用户原句 + 上一轮公开块身份 + 本轮原句
改写产出：独立问句 + same_topic + named_feature_ids
之后：检索 → 重排 → 按本轮块生成（生成集里也没有上轮回答正文）
```

## 2. 主窗 `c-mu6ytn55-g6vlsy`

| 键 | 值 |
|---|---|
| conv_id | `c-mu6ytn55-g6vlsy` |
| 时间 | 2026-09-18 12:59–13:02 UTC（约北京 20:59–21:02）；同窗 14:19 UTC 还有一轮无关问 |
| 窗口 | 同一会话，未新建 |
| 第 1 轮角色 | 验收向 VIP 三问，后面各轮都围着这篇答转 |

### 轮 1 · 知识题（基线，正常）

```yaml
input: "VIP 保级扣的是财富值还是金币？200 金币等于多少财富值？退款怎么扣？"
window_before: 空会话或仅空状态
intent_guess: 按 brief 分段答三问，带出处
rewrite_query: 与原句几乎相同
same_topic: true   # 无历史时模型也常写 true；本轮 last_chunks 为空，无害
named_feature_ids: [vip, recharge, payout]   # 3 路
status: success
n_cgen: 8
output_summary: >
  保级扣财富值（重置为本级初始）、200 金币 = 1 财富值、
  退款按 200 退款金币 = 3 财富值扣除。
gap: 无。这是产品主路径。
```

### 轮 2 · 反问 / 确认

```yaml
input: "你确定么？"
window_before: >
  上一气泡已给出保级 / 比例 / 退款三套数字。
  history 只有轮 1 用户原句，没有回答正文。
intent_guess: >
  核对刚才三句话是否都有块依据；或要把握、不要再分析。
  不是再要一篇同样结构的长答。
rewrite_query: "VIP 保级扣的是财富值还是金币？200 金币等于多少财富值？退款怎么扣？你确定么？"
same_topic: true
named_feature_ids: [vip]   # 从 3 个收到 1 个，分路变单路
status: success
n_cgen: 8
output_summary: >
  再按三问重答一遍；末尾加小节「你确定么？」：
  以上按本轮生成集摘录。
gap: >
  确认句被当成新知识题；点名缩水；
  用户看不到对照上轮结论，只看到第二篇同题作文。
```

### 轮 3 · 约束回答形态（先失败，再答错题）

```yaml
input: "反正你也不确定，就只展示实际，不带有分析对吧？"
window_before: >
  用户已质疑确定性，并规定形态：只摘原文、不要分析。
  history = 轮1原句 + 「你确定么？」。
intent_guess: 短摘录或条目；或确认系统能力边界。不要再讲一遍推理。
```

**3a · 第一次（约 13:01:50 UTC）**

```yaml
rewrite_query: "VIP 保级扣的是财富值还是金币？200 金币等于多少财富值？退款怎么扣？只展示实际，不带有分析对吗？"
named_feature_ids: [vip]
same_topic: true
status: gen_fail
n_cgen: null
output_summary: 错误气泡（重排 400 / 生成失败类），不是「文档未写」。
gap: 形态指令被拼进检索问句；本轮没有答案。
```

**3b · 第二次（约 13 秒后，同句再发或刷新）**

```yaml
rewrite_query: "VIP 保级扣的是财富值还是金币？200 金币等于多少财富值？退款怎么扣？"
named_feature_ids: [vip]
same_topic: true
status: success
n_cgen: 8
output_summary: 又一篇保级 / 比例 / 退款长文。「只展示实际」已从改写句消失。
gap: 形态约束没有进入生成；用户要的是口吻，得到的是原题重答。
```

### 轮 4 · 应酬 / 收口

```yaml
input: "好的"
repeats: 连续两次，间隔约 3 秒（13:02:26 / 13:02:29 UTC）
window_before: history 已含完整 VIP 三问、确认、形态约束。像结束，不是新知识题。
intent_guess: 短回、停止、或不再检索。
rewrite_query: "好的"
named_feature_ids: []
same_topic: true
status: gen_fail   # 两次相同
n_cgen: null
output_summary: 两次错误气泡。检索查询相当于「好的\n好的」。
gap: >
  应酬被送进完整 RAG；独立问句没有沿用上轮知识题。
  召回与上轮 VIP 块容易对不齐；当时上轮公开块无 content 并进重排，空文档导致重排 400。
```

### 轮 5 · 同窗无关问（约 14:19 UTC / 北京 22:19）

```yaml
input: "你知道老王是谁么？"
window_before: 仍是同一 conv_id；前面是 VIP 多轮。
intent_guess: 闲聊或测域外。合理产品行为可以是「不是 Hayyo 规则」，不必翻 brief。
rewrite_query: "你知道老王是谁么？"
same_topic: false   # 换题，不并上轮 VIP 块
named_feature_ids: []
status: refuse
n_cgen: 8
output_summary: 文档未写「老王」是谁；本轮生成集没有这个人物。
gap: 回答方向对了，但仍然走了 embedding + 两库检索 + 重排 + 生成。
```
